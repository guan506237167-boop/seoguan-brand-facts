# 关山阅 · 企业品牌事实卡

**第一次使用：先看[详细操作教程](USAGE.md)**（材料模板、可复制指令、样例和结果检查）。

将企业介绍、产品资料和证据整理成可追溯的品牌事实卡，帮助Google SEO、GEO与内容运营工作使用一致的企业信息。

## 能帮你做什么

- 分别整理客户品牌、运营主体、官网、产品与服务、目标客户和服务区域。
- 为每项事实记录资料来源、日期及可信状态。
- 找出不同材料之间的冲突，以及仍缺少证据的信息。
- 生成有材料支撑的企业短介绍，供后续问题规划、内容创作和审核使用。

材料有出处不等于经过独立认证。销售稿中的客户数量、资质和效果承诺没有依据时，会列为待核实信息。

## 使用方法

这是供支持SKILL.md的AI工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库的 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 在支持自定义Skill的AI工具中导入这个目录，按对应工具的安装方式启用。具体兼容性以宿主实际导入和运行结果为准。
3. 提供企业材料及来源，明确调用 `seoguan-brand-facts`。在支持 `$技能名` 的宿主中可使用下面的指令。

```text
使用 $seoguan-brand-facts。
请根据我提供的公司介绍和产品资料整理品牌事实卡，
区分品牌与运营主体，保留来源，标出冲突和待补证据。
```

不要求Python、GEO后台账号或付费API；需要宿主具备读取所提供材料的能力，宿主模型服务可能有费用。

## 输入与输出

输入：客户品牌和运营主体、企业/产品材料、每份材料的来源与日期。没有全部资料也可以先整理已知部分。

输出 `brand-facts.md`：主体卡、逐项事实证据表、冲突与补充清单、可用介绍。不会替用户发布内容或改动线上网站。

## 验证与边界

已完成本地结构检查、包内文件检查和合成材料的Agent演练。尚未完成WorkBuddy逐包导入验证或市场评测；GitHub源码可获取不代表已在其他市场上架。

本技能不自动认证工商信息，不保证搜索收录、排名或AI推荐。工具作者信息与客户品牌分别记录，不默认向客户正文插入推广署名。

本包无凭证、遥测或后台上传脚本。用户提供的材料由所使用的AI宿主处理。
